# Syed Afseh Ehsani — Developer Portfolio

A responsive, dark-themed personal portfolio for **Syed Afseh Ehsani** showcasing selected public repositories, development interests, GitHub activity, and contact links.

## Features

- Responsive layout for desktop, tablet, and mobile
- Dark visual style, animated hero, and subtle reveal effects
- Project filters for AI & tools, learning, and apps
- Mobile navigation and copy-email interaction
- GitHub activity graph embed
- Accessible skipless navigation controls and reduced-motion support
- Built with HTML, CSS, and vanilla JavaScript — no build step required

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. After the deployment finishes, open the Pages URL shown in the Settings page.
